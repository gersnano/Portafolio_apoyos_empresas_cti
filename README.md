# Portafolio de apoyo empresarial en CTI

Una herramienta de información de la UNE-CTI que reúne y caracteriza los instrumentos públicos de apoyo empresarial en Uruguay. Fecha de referencia del relevamiento: octubre de 2026.

Sitio estático para la coordinación y el análisis de política entre agencias. Un explorador de instrumentos con fichas y un análisis comparado de las instituciones.

## Archivos

- index.html: interfaz, estilos, lógica y datos embebidos (un solo archivo).

 Se publica desde la raíz de main en GitHub Pages.

## Fuentes y alcance

La base de elaboración propia de la UNE-CTI, conserva las líneas y los identificadores de instrumentos. Los conteos se calculan al cargar los datos. Las clasificaciones operativas y estratégicas se distinguen. 

Correcciones: german.pereira@une.uy. El formulario prepara el correo para su envío por la persona que reporta; no almacena información.
